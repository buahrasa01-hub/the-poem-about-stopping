# The poem about stopping

Run with Python 3.13: `python3 main.py`. The program writes `entry.txt` into `/output` by default; set `MAKEFUN_OUTPUT_DIR` to choose another directory.

The poem treats staying as an intentional act that holds another person through a moment of uncertainty, then returns the choice of direction to them.
